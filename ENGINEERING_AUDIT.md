# Ion IDE engineering audit

## Stabilization follow-up from 9adcdea

The Git race reproduced against the exact checkpoint source. `SourceControlService.change` called `checkRepositoryFilters`, then a separate Git process ran `add`. The fixture inserted `filter.late.clean` between validation and the real spawn. `.gitattributes` selected that name and Git executed the new command, writing a marker in the disposable repository. This crosses a configuration-to-execution boundary. Workspace path validation and repository trust do not make those separate reads atomic.

`git` in [repository.ts](src/main/source-control/repository.ts) now captures the effective configuration with scopes and resolved includes. [configuration.ts](src/main/source-control/configuration.ts) validates that captured input, removes include references and unused network credentials, and runs status/staging through a private metadata view containing the checked configuration. Original config/include changes cannot affect that operation. Live objects and ref reads, conditional global settings, text normalization, split indices and linked worktrees are preserved. Ref publication uses native Git against the original repository and compares the reviewed branch's old object ID before updating it. [Git configuration scopes](https://git-scm.com/docs/git-config#_scopes)

Local executable filter and LFS extension/transfer definitions are refused. Approved global filters remain user-authorized executable tools. Six genuine Git LFS integrations passed on macOS, covering durable original-common storage, relative/absolute storage, linked worktrees and a late executable-extension injection. A custom filter that creates extra metadata inside the private view causes Ion to preserve that view and reject staging before publishing an index that depends on disposable data. The error supplies its recovery path. This configuration boundary does not provide an operating-system sandbox. [Git LFS configuration](https://github.com/git-lfs/git-lfs/blob/main/docs/man/git-lfs-config.adoc) · [Genuine LFS fixture](scripts/test-git-lfs.mjs)

Stage and Unstage use [index-transaction.ts](src/main/source-control/index-transaction.ts). Ion owns the real exclusive index lock while Git writes a bounded private index beside the original, preserving shared split-index lookup. Success publishes Git's completed bytes and permissions. Cancellation preserves the old index and cleans only owned locks and temporary names. [SourceControlService](src/main/source-control/index.ts) now retains and aborts its write controller on close. Closing during the final bounded `update-ref` waits for reviewed ref publication to finish. A process crash or forced filesystem failure can still require ordinary Git lock recovery.

The [standalone race reproducer](scripts/test-git-configuration-race.mjs) demonstrated filter execution on `9adcdea` and prevented the same late command in the fixed source. Both runs verified exact staged bytes. [Native Git unit integrations](test/source-control.test.ts) cover changed includes, worktree process filters, conditional global filters, config escaping, split indices, lock ownership, a genuine slow-filter cancellation and closing during final commit publication. The native Windows run at `a4e0345` also passed the race reproducer, six genuine LFS cases, Git desktop workflows and shutdown checks. Final release evidence must match the tag's own completed run.

Native verification exposed two further correctness defects. The old Windows helper's rooted Win32 rename failed the save and conflict fixtures. The helper now uses `NtSetInformationFile` with `FileRenameInformation` and its pinned parent handle. All ten Windows scoped filesystem and conflict tests passed, including Unicode, long paths, case aliases, sharing locks and competing mutations. No path protection was relaxed. The original error code was lost by the previous wrapper, so the precise historical Win32 rejection is unproven. The revised helper retains numeric native diagnostics on failure. [Native rename contract](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/ntifs/ns-ntifs-_file_rename_information)

The private Git index initially acquired a fresh copy timestamp. That can invalidate Git's racy-index protection and stage old bytes after a same-size edit on a coarse clock. A deterministic fixture reproduced this on macOS before the fix, then passed after preserving timestamps, rounded down conservatively, on both the private copy and final publication. The complete Git suite now has twenty cases. Separately, Monaco's `fsPath` lowercases Windows drive letters. Cross-file C/C++ and Java definition navigation now uses the decoded URI path with its original drive spelling. Main-process workspace authorization remains unchanged. [Timestamp regression](test/source-control.test.ts) · [Source path conversion](src/shared/source-path.ts)

The shutdown investigation reproduced harness defects. An open Run Tests dialog deliberately declines quit, after which cleanup used to replace the workload's primary error with an eight-second timeout. Calling Playwright's `ElectronApplication.process()` after natural exit also accessed a disposed dispatcher. On Windows, force-killing only the main process after a failed test orphaned Chromium children holding disposable profile databases. Failed test teardown now terminates the owned Windows process tree, preserves the original error, and has a checkpointed-recovery regression. The [harness](scripts/desktop-harness.mjs) retains its child-process handle and bounded lifecycle/console diagnostics. The [shutdown fixture](scripts/test-shutdown-stability.mjs) exercises draft recovery, approved quits, cancellation and descendant cleanup. The exact historical workload error remains unavailable. Baseline testing passed 24 launch/quit cycles, recovery, a running terminal/program descendant and a running approved suite, with zero captured process survivors.

The [memory harness](scripts/benchmark-stabilization-memory.mjs) records natural recovery at 20 seconds, two minutes and five minutes, with per-process RSS/footprint, heap and DOM counters. It verifies the stable Monaco creation host and original undo history. A pilot initially checked a replaceable model-view element. That assertion was corrected and the baseline rerun. Results and incomplete attempts are reported in [PERFORMANCE.md](PERFORMANCE.md). All four native branch gates passed at 3d2998c. The final local production session completed fifteen minutes, 180 editing rounds and 45 C executions, with normal exit and no observed surviving app family. Final local type checking, 195 unit cases (183 passes, 12 documented skips), four release/signing cases and a source-history credential scan passed. Exact-tag run 43089559300, attempt 1, then passed all four jobs at 18a5eea. Both installer manifests and published GitHub digests matched, and 0.9.6 was published with macOS and Windows installers. The installed 0.9.5 app was left in place and its actual title-bar update button was verified against that public release. [Release](https://github.com/Vaddi-Srisanth/Ion_IDE/releases/tag/v0.9.6) · [Exact-tag verification](https://github.com/Vaddi-Srisanth/Ion_IDE/actions/runs/43089559300). ## Architecture, privilege and data boundaries

- `createWindow` uses one primary workbench, `contextIsolation`, `sandbox`, `nodeIntegration: false` and no webview. It denies new windows and renderer navigation. `registerSession` serves packaged assets from a canonical root with a CSP and blocks renderer HTTP and WebSocket traffic outside the explicit development exception. Preview HTML executes in a separate network-denied Electron session without the workbench preload. [Main window and protocol](src/main/index.ts) · [Web preview](src/main/web-preview.ts)
- `registerIpc` wraps privileged calls with `owner`. Sender identity, top frame and exact workbench URL are checked for every invocation. The [preload](src/preload/index.ts) exposes a named bridge, and [contracts](src/shared/contracts.ts) supply TS shape information. Main still validates roots, limits, revisions and operation-specific input. For example, a saved-suite invocation cannot supply an executable or shell line. [Project handlers](src/main/projects/ipc.ts)
- `WorkspaceFiles` applies a canonical root and explicit file grants. Path and revision checks reject ordinary stale or symlinked files. A content hash accepts metadata-only differences when the underlying bytes still match. The candidate uses a no-clobber native publication for a new Save As destination. Existing destinations are explicitly confirmed. The audit demonstrated races between validation and actual mutation. Parent authorization and mutation must share an enforceable filesystem boundary. [File operations](src/main/files.ts) · [Native mutation adapter](src/main/file-mutations.ts)
- Local source, tests, shells and notebook kernels run with the account's permissions. Explicit Run and first kernel start are trust-gated. Tool selection excludes workspace executables where the existing policies require installed tools. Native process ownership, output quotas and time limits control cleanup. The tests do not establish containment against deliberately evasive programs. [Run gate](src/main/index.ts) · [Process executor](src/main/runner.ts) · [Windows process adapter](src/main/windows-process.ts)
- Project planning sends only the separately approved description. The key stays in the main process vault, is discarded on provider endpoint change and is excluded from profile export. Markdown and notebook markup sanitize content. Document worker inputs and imported packs are declarative and bounded. Git protects hooks, fsmonitor, network protocols and local filters in the ordinary path. EA-04 qualifies the timing of the filter guard. [Provider](src/main/projects/provider.ts) · [Markdown](src/renderer/markdown/MarkdownPreview.tsx) · [Notebook content](src/renderer/notebooks/notebook-content.tsx) · [Git adapter](src/main/source-control/repository.ts)
- Source text lives in Monaco or a detached dirty record. `Documents.changed` schedules per-record recovery and autosave, and changes the tab snapshot on dirty-state transition. Cursor display updates through a ref and terminal output uses a separate store. Search, lesson, preview and source-tool requests are scoped and lazy. The audit did not measure IPC byte volume or React commits per keystroke. Measure those before extracting broad state infrastructure. [Editor store](src/renderer/documents.ts) · [Workbench](src/renderer/Workbench.tsx) · [Terminal store](src/renderer/run-console/store.ts)

An interception inserted the competing action at a specific boundary. It did not substitute a simulated result. The scripts and transcript are local ignored outputs in `performance-results/git-tests/audit/`. The same scoped filesystem fixtures now pass on native Windows. ## Maintainability and follow-through

### File safety verification boundary

All six deterministic file-mutation cases passed in the hardened macOS unit regression. macOS uses an atomic name exchange for the existing-file replacement and retains the displaced entry. Windows opens path components and file leaves relative to pinned directory handles, checks their identity and rejects reparse points. Its two no-clobber moves retain the old file before publishing. An interruption between moves can temporarily leave the original name absent with its bytes in an adjacent recovery file. A competing arrival is preserved, and restoration is attempted only if the original name is free. Windows Create stages through exclusive, rooted file creation and flushes bounded raw input before publication. A failed staged write deletes its own incomplete entry through its held handle when possible. The Windows source compiled to an amd64 COFF object with Zig 0.17.1 targeting `x86_64-windows-gnu` under C++17 and `-Wall -Wextra -Werror`. Native runtime, sharing-lock behavior, directory case changes and an interrupted Windows transaction still need evidence. Trash staging needs a common volume between the workspace and the app's holding directory. Cross-volume requests fail safely and require the system file manager. [Race tests](test/file-mutation-races.test.ts) · [macOS helper](src/main/native-file-mutations.c) · [Windows helper](src/main/native-file-mutations-windows.cpp) · [Windows handle rename](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_rename_info)

`main/index.ts` and `App.tsx` each exceed 1,400 lines at inspection. The cost is concentrated ownership of feature initialization, cancellation, window transitions and status routing. Preserve the existing on-demand modules and extract seams only where regression tests and traces identify duplication or fragile state transitions. The same principle applies to the distinct bounded JSON stores. Their schema, compatibility and lifecycle concerns differ. No measured serializer bottleneck warrants merging them or migrating storage.

The matched development workload used three trials on an Apple M3 with 24 GiB, a 1,000-file workspace, ten tabs, a 7,000-line diff and four approved C cases. Keep whole-tree summed RSS, macOS-attributed footprint, per-process metrics and CPU intervals separate. The typing proxy reaches the second renderer animation callback. Physical scan-out, Windows GPU, CPU consumed by children that exit between samples and hours-long workloads require separate measurement. This baseline predates the P0 file and Git race fixes. [Measured workloads](PERFORMANCE.md) · [Development benchmark](scripts/benchmark-development-workflows.mjs)

Verify the P0 fixes first with deterministic native competing actions and re-run ordinary save, recovery, rename, Git and suite regression tests. Then profile model eviction, active diffs and optional pane lifetimes under a matched workload. Keep Git and test feature gates, viewport/assistive-technology verification and the two-platform release gates explicit. A successful earlier regression does not settle the race register.
