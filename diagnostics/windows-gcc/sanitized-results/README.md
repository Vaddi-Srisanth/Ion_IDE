# Shareable diagnostic evidence

`historical-evidence.json` is a sanitized extraction of existing native receipts, not a new benchmark. Original hashes and source checkpoints are retained. No raw document/code output, path, profile, API key or user name is included.

There are currently **no new Windows measurements**. The Windows harness creates a separate `sanitized-results/` beneath each new disposable run directory. Review it before sharing. Native behavior remains unverified and the release remains held.
