The full test run was not clean on this host and must not be represented as a final release gate. Windows symbolic-link fixtures could not run because the account lacks symbolic-link privilege. The installed `C:\MinGW\bin\gcc.exe` is too old for `-std=c17` and mishandled a Unicode fixture path, so C lifecycle and GCC diagnostic cases failed while the corresponding C++ cases passed. One source-control cleanup encountered a busy fixture directory, and one Windows sharing-lock assertion failed during the loaded suite. The installed-app verifier was not run because this machine already has Ion IDE 0.9.6 installed; that verifier requires a disposable machine without an existing installation.

Run the repository's native release workflow on a disposable Windows x64 host before general publication. The installer exceeds GitHub's 100 MiB per-file Git limit, so distribute it as a GitHub release asset with its checksum rather than committing it to repository history.
