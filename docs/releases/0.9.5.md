## Updates in the title bar

When a compatible release is available, click **Update available** at the top of Ion to download its installer from GitHub. Ion verifies the installer checksum before saving it in Downloads. Open the installer yourself when you are ready. You can check in **Preferences → Updates** or enable **Check for updates on launch** there. To upgrade from 0.9.4, use its existing **Preferences → Updates** panel once.

## Learning Lens

Install and select the C pack in **Learn**, run a saved C file, and choose **Explain** in **Problems** for a recognized compiler error. The Lens connects the diagnostic to its current source location and an offline lesson. Editing clears stale highlights. **Explain Again** lets you revisit a recurring error after a meaningful code change. When a successful compile confirms the error is gone, Ion records the resolution in local history. A resolution records a compiler outcome. For ambiguous diagnostics, Ion keeps the original message and indicates that it has no reliable explanation. The Lens is optional and works offline. ## Other candidate changes

- **Document formatting.** Format the active buffer from the status bar, command palette, or a configurable shortcut. Ion uses installed formatters offline and applies the result as one undoable edit. [Formatter setup](../USAGE.md#format-a-source-file) · [Performance measurements](../../PERFORMANCE.md#format-document)
- **Java editing.** Java snippets work offline. Smart Java optionally uses an installed JDK for semantic suggestions, method signatures, navigation, and live diagnostics. [Java editing guide](../USAGE.md#java-suggestions-and-diagnostics) · [Performance measurements](../../PERFORMANCE.md#smart-java)
- **First launch.** The optional introduction leads to setup for the four existing workspaces. Reduced motion uses a static screen, and Preferences can replay the intro. [First-launch guide](../USAGE.md#first-launch)
- **Learn and Practice.** Browse 19 offline learning packs with 162 lessons. Supported exercises open a practice attempt with starter code and local sample tests. Reviewed diagnostics can link to lessons for C, C++, Java, Python, and JavaScript, with coverage depending on the toolchain and error. [Pack guide](../LEARNING_PACKS.md)
- **Terminal.** Open a shell session on demand beside the existing Run Console. macOS uses the configured shell. The verified Windows preview uses Command Prompt. Closing a session ends its shell and child processes. Hiding the panel keeps the session running. [Performance and lifecycle](../../PERFORMANCE.md#integrated-terminal-on-macos)
- **Local builds.** An explicit `.ion/build.json` can list sources for a multi-file C or C++ executable. On Windows, supported Maven and Gradle projects can run offline with a local JDK, installed build tools, and cached dependencies. [Windows build and toolchain prerequisites](../windows/BUILD.md)
- **Windows reliability.** Added Open With registration and strengthened saves, rename handling, and recovery around Windows path and file-lock behavior. [Windows readiness evidence](../../WINDOWS_RELEASE_READINESS.md)
