# Ion IDE 0.9.6 preview

Ion is a personal project by Vaddi Srisanth. Everyone is welcome to test this preview and report reproducible problems.

[Download installers and checksums](https://github.com/Vaddi-Srisanth/Ion_IDE/releases/tag/v0.9.6) · [Usage guide](../USAGE.md) · [Changelog](../../CHANGELOG.md)

## Reliability fixes

- Git staging uses a validated configuration snapshot. A repository cannot add a new executable filter between Ion's check and its staging command. Regression fixtures exercise real Git, included configuration, linked worktrees and Git LFS.
- Staging and unstaging publish through an owned index transaction. Cancellation preserves the original index and cleans owned temporary files. Original index timestamps are retained conservatively so rapid same-size changes are rechecked instead of staging stale bytes.
- Windows save, rename and Trash operations use rooted native renames with pinned parent handles. Native tests cover competing file changes, Unicode, long paths, case aliases, junction boundaries and sharing locks.
- Shutdown tests cover recovery drafts, canceled closes, active programs, terminals and approved test runs. Test cleanup preserves the original failure and records useful exit diagnostics.

## Development workflows

- **Source Control:** local branch and file status, Explorer badges, staged and working-tree text diffs, Stage, Unstage and local commits. Git starts when needed. Remote operations, signed commits and repository-local executable filters remain terminal workflows.
- **Run Tests:** save and approve C console behavior tests in Projects, run a case or suite, compare actual output and exit codes, follow compiler locations and retain verified local results.
- **Navigation:** relative breadcrumbs and Back/Forward source locations. Optional Smart C/C++ uses installed clangd for definitions and references with background indexing disabled.
- **Themes:** sixteen small offline palettes, including high-contrast variants, with search, reversible previews, favorites, automatic appearance and custom JSON import/export.

The existing editor, autosave, recovery, Run Console, Terminal, Learning Lens, offline packs, Practice, project planning, Markdown, notebooks and document previews remain available. Language support and required local tools are listed in [the README](../../README.md#features).

## Install and update

Download the installer for your operating system and compare its SHA-256 with `SHA256SUMS` from this release.

- **Apple Silicon macOS:** open `Ion-IDE-0.9.6-mac-arm64.dmg`, then drag Ion IDE to Applications. The app is ad-hoc signed and unnotarized. Gatekeeper may require approval.
- **Windows x64:** run `Ion-IDE-0.9.6-windows-x64-setup.exe`. Setup is unsigned, so SmartScreen or local policy may show a warning. The upgrade test uses the real public 0.9.5 installer and checks that local settings and unrelated files survive.

In Ion 0.9.5, open **Preferences → Updates → Check for Updates**. Close Preferences after the check to see **Update available** in the title bar. Click it to download and verify the matching installer from GitHub. Installation remains your choice. Launch checks are optional and normal offline editing makes no update requests.

## Evidence and limits

The release build requires passing native macOS and Windows desktop, installer and process-tree benchmark jobs for the exact tag. Installer manifests identify the source commit, Actions run and attempt, byte count and SHA-256. [Verification workflow](https://github.com/Vaddi-Srisanth/Ion_IDE/actions/workflows/desktop-build.yml) · [Engineering audit](../../ENGINEERING_AUDIT.md) · [Performance report](../../PERFORMANCE.md)

This stabilization does not claim a RAM reduction. Matched macOS measurements separate attributed footprint from summed RSS, show natural recovery after activity, and retain the observed differences and incomplete attempts. The old Windows checkpoint cannot complete the same workflow because its save operation fails, so it cannot supply a valid full-workflow comparison. Physical 8 GiB hardware, manual retail Windows 10/11 qualification, a four-hour session and exact retained native allocation ownership remain open.
