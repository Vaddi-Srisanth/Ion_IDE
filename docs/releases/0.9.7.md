# Ion IDE 0.9.7 — In-place Updates and Run Trust

Ion is a personal, offline-first IDE project. Everyone is welcome to test this public preview and report problems. The project has no general reuse license; dependency licenses remain applicable.

## What changed

- **Install and Restart** replaces the existing installation after downloading and checking the GitHub installer. Ion uses its normal Save, Keep Drafts or Cancel flow before handing off. Local settings, recovery and projects live separately from application binaries.
- **Optional folder trust** stops repeated single-file Run prompts in your own workspace. Check **Trust this folder for future single-file Runs** in the Run confirmation. Revoke remembered approvals in Preferences → Run Console. This does not automatically run anything, and it does not approve project builds, tests, notebooks or Git.
- An explicit, on-demand runtime sampler records real process-tree footprint, summed RSS and CPU, with offline charts and raw samples. It does not run as an application background service.

## Download and install

Use the Apple Silicon macOS `.dmg` or the Windows x64 `setup.exe` attached to this release. Compare the downloaded file with the attached `SHA256SUMS`.

Versions through 0.9.6 only download updates. Install 0.9.7 once into the same Mac Applications folder as your existing app, or run Windows Setup. From 0.9.7 onward, the title-bar flow is **Update available → Download → Install and Restart**. A current installation correctly reports that it is current; it does not display a fake update.

Keep one installed copy. `/Applications/Ion IDE.app` and `~/Applications/Ion IDE.app` are different locations. Updates started from 0.9.7 target the running installed copy. Portable copies and read-only disk images are refused instead of silently creating another installation.

## Security and verification limits

The Mac preview is ad-hoc signed and unnotarized; Windows Setup is unsigned. Gatekeeper, SmartScreen or organization policies may require user approval or block launching. Ion preserves download security metadata and never disables OS protections. An installer checksum verifies consistency with the GitHub release, not an independent developer certificate.

Native Mac tests exercise actual signed fixture bundles and atomic replacement. Windows tests run on the hosted native x64 runner with locally built unattended fixtures; approval of an Internet-marked unsigned installer remains an interactive OS check. These do not replace Windows 10/11 retail hardware or an 8 GB laptop pilot.
