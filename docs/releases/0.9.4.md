# Ion IDE 0.9.4

Ion IDE is a personal project by Vaddi Srisanth. Everyone is welcome to try it and share feedback. Write and run local code in Free Coding, or open Learn, Projects, and Practice beside the editor when you want them.

## Changes

- Search workspace text from the sidebar and jump to matches. Open oversized text files in a paged read-only tab.
- Save with external-edit checks, and resume a session with checkpointed drafts and source positions.
- Build a Windows x64 preview installer from the same source tree. Windows standalone programs use line-based input. [Windows details](../windows/FEATURE_PARITY.md)
- Check for GitHub Releases and download a verified installer from **Preferences → Updates**. Open the installer yourself when you are ready to update.

## Installer assets

After publication, the release’s **Assets** list the installers. [Releases](https://github.com/Vaddi-Srisanth/Ion_IDE/releases)

| Target | Asset | Install |
| --- | --- | --- |
| Apple Silicon macOS | `Ion-IDE-0.9.4-mac-arm64.dmg` | Mount the disk image and drag Ion IDE to Applications. |
| Windows x64 preview | `Ion-IDE-0.9.4-windows-x64-setup.exe` | Run setup, then open Ion IDE from Start. |

The Mac build is ad-hoc signed and has no notarization. Windows setup is unsigned, and native Windows runtime verification is pending. Install local compilers or interpreters for the languages you want to run. [Install and toolchain instructions](../../README.md#download-and-install)

For a bug report, include the Ion version, operating system, and reproduction steps with a small example you can share. [Issues](https://github.com/Vaddi-Srisanth/Ion_IDE/issues) · [Security reports](../../SECURITY.md)
