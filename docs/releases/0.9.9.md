# Ion IDE 0.9.9 for macOS Apple Silicon

Open several folders in one workspace, split a file across editor groups, and keep one undo history as you move between views. Explorer and tab context menus, keyboard navigation, and reviewed search-and-replace make larger assignments easier to manage.

- **Code navigation.** Request completions, diagnostics and navigation using installed Java, clangd, Pyright and TypeScript tooling. Review supported rename and workspace edits before applying them.
- **Debug C and C++.** With the supported local compiler and LLDB adapter installed, set breakpoints, step, inspect variables and watch expressions in Ion.
- **Build tasks.** Use **Run Task** to discover supported project files, review the command, and follow or stop it in the Run Console. Native acceptance covers npm on both platforms. Custom workspace task definitions and problem matchers remain open.
- **Protect your work.** Back up local settings, lessons, practice records and recoverable drafts. Review conflicts before restoring. Ion keeps a rollback backup and asks again for execution approvals.
- **Learn offline.** Access built-in lessons directly and try practical Python, Java and C exercises. Project Lens uses local project evidence.
- **Keep optional tools on demand.** Ordinary editing starts no language server, debugger or task process. The final macOS Apple Silicon and Windows x64 task checks verified execution, Stop and process cleanup.

**Install or update on Mac.** Download the Apple Silicon DMG and compare its SHA-256 with the attached `SHA256SUMS`. Save your work, quit Ion, open the DMG and drag Ion IDE into the Applications folder that already contains your copy. Choose **Replace**. Ion 0.9.6 downloads this installer from **Preferences → Updates → Check for Updates**. Later supported versions offer **Install and Restart**.

**Windows.** The latest public Windows x64 installer remains [v0.9.6](https://github.com/Vaddi-Srisanth/Ion_IDE/releases/tag/v0.9.6). This 0.9.9 release contains the Apple Silicon DMG and its checksum.

**Preview scope.** The macOS application is ad-hoc signed and unnotarized. Gatekeeper may request approval. Python/Java debugging and the general Test Explorer remain in development. Existing saved C tests remain available. The [engineering report](https://github.com/Vaddi-Srisanth/Ion_IDE/blob/6bbef21c0aaf6fb80d11d10d037d88d48a9390f7/docs/master-plan/ION_ENGINEERING_HANDOFF_THROUGH_2_5.md) covers measurements, tested configurations and limitations.
