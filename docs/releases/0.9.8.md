## Remaining limitations

The original rare Windows GCC delay has not been explained, although a later 909-attempt cohort completed without timeout. macOS warm startup was 54.40 ms slower in the 20-pair comparison; no causal optimization is claimed. Native physical 8 GiB hardware, a four-hour final-candidate session, Developer ID/notarization and Windows publisher signing remain unverified. Preview builds are ad-hoc signed on macOS and unsigned on Windows. The local macOS development registration crash remains uncharacterized; avoid repeated development GUI launches here.

## Installation safety

The local Mac update uses the existing installer to replace the one installed `Ion IDE.app`, after the app has quit. It verifies the bundle and keeps a rollback ZIP outside Applications. Settings, project files and recovery data stay in their existing locations. No duplicate installed application is needed. Do not infer public update availability from this source commit; only a separately authorized, verified GitHub Release changes that feed.
